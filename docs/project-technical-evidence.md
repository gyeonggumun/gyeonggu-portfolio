# 프로젝트 기술 자료와 수치 기준

확인일: 2026-11-04. 팀 프로젝트 7개와 개인 프로젝트 4개, 본문·시연영상 총 51페이지를 대상으로 정리했습니다.

## 코드와 시각 자료

- `src/data/codeExcerpts.js`의 21개 발췌는 GitHub 고정 커밋의 원문입니다. 파일 경로·커밋·blob SHA·줄 번호를 보관하고 원문 링크를 제공합니다. 중간을 생략한 경우 화면에 `···`를 표시합니다.
- 발췌 21개 모두 해당 GitHub 원문의 줄과 일치하는지 확인했습니다. 다른 프로젝트를 고친 예시 코드나 AI가 작성한 코드를 원본 코드로 넣지 않았습니다.
- 본문 이미지 표시를 90곳에서 39곳으로 줄였습니다. 반복 화면·상장 중복·담당 범위와 거리가 있는 캡처를 제외하고, 코드 패널 21개와 기술 기록 패널 7개를 배치했습니다. 카드 대표 이미지·상장/교육 섹션·시연영상은 유지했습니다.
- SafeStay·CleanTicket·GrayGuard에는 공개 실행 코드가 없어 GitHub README의 구현 기록을 기술 표로 구성했습니다. 실제 규칙·로그·백업 결과 캡처는 관련 설명 옆에 유지했습니다.
- DramaCalendar는 공개 GitHub에 실행 소스가 없습니다. 프론트엔드의 날짜 Map·모달 제어는 기존 결과보고서의 코드 캡처로 제시하며, 백엔드 코드를 개인 프론트엔드 기여로 추가하지 않았습니다.
- 워게임의 취약 코드는 교육용 시나리오입니다. 코드와 관측 기록을 설명하며 이번 작업에서 VM을 부팅하거나 공격을 재실행하지 않았습니다.
