## 첨부 자료 분석

- `졸작ppt.pptx`: 10장. 3쪽 문제 정의, 5쪽 전체 구조, 8쪽 프론트엔드, 10쪽 결과·후속 연구를 확인했다. ZIP/OOXML과 python-pptx로 본문과 이미지 원본을 읽었다. PPT 자체를 수정하지 않았다.
- `졸업논문_찐찐막.hwp`: 본문과 포함 이미지 8개를 읽었다. 논문명·공동 작성자·문제 배경·설계·구현·기능 평가·결론을 확인했다.
- `5.졸업작품_결과보고서_심사용_dramaCalendar.hwp`: 본문과 포함 이미지 9개를 읽었다. 표지의 2025.11.22, 역할 분담의 문경구 프론트엔드, 구현·검증·추진 일정을 확인했다.
- `image (3).png`: 사용자가 제공한 장르 페이지 실행 화면. 실제 포스터 대신 placeholder가 보이는 상태를 그대로 사용했다.
- HWP는 OLE 스트림을 읽고 압축 본문·이미지를 추출했다. 한글 문서의 지면을 렌더링한 화면이 아니므로 코드·도식 이미지 원본과 본문 내용으로 표현했다.
- HWP의 인라인 제어 문자 때문에 텍스트 추출에 일부 잡문자가 섞인다. 제목·문단·이미지를 대조했고, 초안의 오타나 자체 평가를 새로운 정량 성과로 확대하지 않았다.

## 주장과 공개 범위

- 졸업작품 개발과 졸업논문 공동 작성의 연결을 설명한다. 학술지 게재·학회 발표를 주장하지 않는다.
- 프론트엔드 역할은 사용자 확인·역할 표·문서의 구현 설명에 따른다. DB·ETL·백엔드·크롤러는 팀 작업으로 구분한다.
- 프론트 코드 캡처에서 toDateKey·buildDailyBucket·useEffect의 실제 로직을 확인했다. 날짜 처리 전체와 중첩 모달·접근성이 모두 검증됐다는 의미는 아니다.
- 문서에는 정성적인 안정성·편의성 평가가 있으나 정량 실험값은 없다. 성능 개선율·사용자 수·응답 지연을 새로 만들지 않았다.
- 개발 연도는 2025년 결과보고서 기준으로 표시했다. 구체적인 개발 시작·종료일은 임의로 정하지 않았다.
- TypeScript는 프로젝트 기술로 명시한다. 프로필 기술 목록에 대한 이전 Node.js 요청은 변경하지 않았다.
- 원본 HWP·PPT의 연락처·학번·서명란 등은 업로드하지 않았다. 논문 원문 대신 개인정보가 없는 요약 문서만 공개한다.
- 제공된 시연영상이 없으므로 빈 영상 페이지 없이 본문 4쪽으로 구성했다.
- 기존 `team-05` 자리에 추가했고 ‘그 밖의 작업들 → 팀 프로젝트’에서 펼쳐 볼 수 있다.
